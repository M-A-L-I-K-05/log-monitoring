3.4. Реализация контура детекции аномалий

Контур точечной детекции отвечает за обнаружение уже наступивших отклонений в потоке сенсорных показаний. Его работа распадается на два больших процесса: обучение на нормальном режиме, которое выполняется один раз, и скоринг - постоянная проверка свежих показаний по обученной норме. Внутри скоринга показания проходят через несколько шагов: подготовку данных, расчёт отклонений, комбинированное решающее правило и проверку устойчивости. Ниже эти процессы рассматриваются по порядку, вместе с формулами, по которым они вычисляются.

Начнём с обучения. Сначала сервис запрашивает из Loki большой пакет последних показаний нормальной работы - событий sensor_reading (раздел 2.4). Каждая такая запись приходит в виде JSON-строки, внутри которой лежит словарь показаний всех датчиков станка в один момент времени. Эти строки разбираются и собираются в таблицу, после чего группируются по паре станок-контекст: контекстом служит тип обрабатываемой шестерни для обычных станков и фаза цикла для печи (листинг Г.2). Внутри каждой группы данные разворачиваются в таблицу, где строки - это моменты времени, а столбцы - отдельные датчики; в ячейках стоят их показания. Именно такая таблица и подаётся на обучение.

Важная деталь обучения - данные берутся в сыром виде, с исходным интервалом 15 секунд, без приведения к равномерной шкале и без заполнения пропусков. Это сделано намеренно. Станок присылает показания только во время работы, а в простое поток прерывается; если выровнять ряд по времени и закрыть пропуски повторением последнего значения, разброс данных искусственно сожмётся, и стандартное отклонение нормы окажется заниженным вдвое и более. На скоринге такая заниженная норма привела бы к завышению отклонений и потоку ложных срабатываний. Поэтому норма оценивается строго по сырому ряду. Обучающую выборку составляют последние показания комбинации - порядка тысячи точек на каждую пару станок-контекст, что при интервале 15 секунд соответствует примерно четырём часам работы станка; обучение не запускается, если доступно менее тридцати точек.

По этой выборке для каждого датчика j отдельно вычисляются два числа, задающие его норму, - среднее m_j и стандартное отклонение s_j по формулам (3.1) и (3.2):

m_j = (1 / N) Σ x_ij,     (3.1)

s_j = √( (1 / N) Σ (x_ij - m_j)² ),     (3.2)

где x_ij - i-е из N обучающих показаний датчика j; Σ - суммирование по всем обучающим точкам i; N - размер обучающей выборки. Стандартное отклонение в формуле (3.2) берётся в варианте с делением на N, то есть по фактическому разбросу самой обучающей выборки. Среднее задаёт, где показание держится обычно, а стандартное отклонение - насколько сильно оно колеблется вокруг этого среднего.

Кроме нормы, на тех же точках обучаются два многомерных детектора, которые смотрят на показания всех датчиков совместно и улавливают необычные сочетания, незаметные при пораздельном контроле. Первый - Isolation Forest [6]. Он строит ансамбль случайных деревьев, в которых данные многократно разбиваются по случайному признаку и случайному порогу; аномальная, обособленная точка отсекается меньшим числом разбиений, то есть оказывается ближе к корню. Мерой аномальности служит средняя длина пути до точки по всем деревьям, нормированная на ожидаемую длину пути в дереве из n точек, и определяется формулой (3.3):

s_if(x) = 2 ^ ( - E(h(x)) / c(n) ),     (3.3)

где h(x) - длина пути до точки x в одном дереве; E(h(x)) - её среднее по всем деревьям; c(n) = 2 H(n - 1) - 2(n - 1) / n - средняя длина пути в дереве, построенном на n точках; H(k) = ln(k) + 0,5772 - гармоническое число (0,5772 - постоянная Эйлера-Маскерони). Значение s_if в формуле (3.3) близко к единице - точка аномальна, около 0,5 и ниже - нормальна.

Второй детектор - ECOD [7]. Он непараметрический: по обучающей выборке для каждого датчика строится эмпирическая функция распределения F_j, а аномальность точки оценивается по тому, насколько глубоко её значение сидит в хвосте этого распределения. Вклады по всем датчикам складываются отдельно для левого и правого хвоста, и берётся больший из них, что даёт оценку (3.4):

O(x) = max( - Σ ln F_j(x_j),  - Σ ln (1 - F_j(x_j)) ),     (3.4)

где F_j(x_j) - доля обучающих показаний датчика j, не превышающих x_j (левый хвост); 1 - F_j(x_j) - доля превышающих (правый хвост); Σ - суммирование по всем датчикам j. Чем глубже значения в хвостах, тем меньше эти вероятности и тем больше итоговая оценка O(x). Оба детектора применяются через единую библиотеку с общим интерфейсом [8]. Результат обучения - норма по каждому датчику и две обученные модели - сохраняется в томе и переиспользуется после перезапуска контейнера без повторного обучения.

Многомерные детекторы выдают для каждой точки не метку, а число - оценку аномальности, и рабочий порог этого числа калибруется тоже по обучающим данным. Для каждого детектора берётся набор его оценок на обучающей выборке, и порог устанавливается по формуле (3.5):

t = mean(o) + 3 std(o),     (3.5)

где o - оценки детектора на обучающих точках; mean(o) и std(o) - их среднее и стандартное отклонение. Точка помечается детектором как аномальная, если её оценка превышает порог t. Такой порог не привязан к заранее заданной доле выбросов, а определяется собственным разбросом нормальных оценок: на чистом нормальном фоне за него выходит порядка 0,1 процента точек, что соответствует правилу трёх стандартных отклонений [11].

Теперь скоринг. Раз в несколько секунд сервис берёт свежее окно последних показаний и прогоняет его через обученные модели. Но перед этим окно проходит подготовку, которая отличается от обучения: показания усредняются до минутного шага - четыре последовательных значения по 15 секунд сворачиваются в одно среднее за минуту. Смысл усреднения в том, что случайный шум датчика при этом гасится: при усреднении нескольких независимых отсчётов разнонаправленные колебания взаимно сокращаются, и минутный ряд оказывается примерно вдвое спокойнее сырого. При этом норма по-прежнему измеряется в сырой, более громкой шкале, поэтому случайные шумовые всплески на минутном ряде уже не дотягивают до порога и не порождают ложных тревог. А вот реальный дрейф - устойчивый сдвиг среднего, который и означает развивающуюся неисправность, - усреднение не гасит: он остаётся на месте и спокойно проходит порог. Так подготовка данных заодно отсеивает шум, сохраняя полезный сигнал.

На подготовленном окне для каждого датчика вычисляется его отклонение от нормы в стандартных отклонениях - z-оценка по формуле (3.6):

z_j = (x_j - m_j) / s_j,     (3.6)

где x_j - наблюдаемое значение датчика j; m_j и s_j - его норма из обучения по формулам (3.1) и (3.2). По смыслу величина в формуле (3.6) отвечает на вопрос, на сколько сигм текущее показание ушло от своего обычного значения. По станку берётся не сумма и не среднее этих отклонений, а максимум модуля по всем его датчикам согласно (3.7):

Z = max |z_j|.     (3.7)

Выбор максимума принципиален: один выскочивший датчик всегда заметен и не разбавляется значениями нормальных, тогда как при суммировании или усреднении единичное отклонение размылось бы среди шести-восьми спокойных показаний. Точка считается подозрительной по z-правилу, если величина Z из формулы (3.7) достигает порога 2,8.

Поясним порог на примере. Пусть у виброскорости токарного станка норма m = 0,8 мм/с при стандартном отклонении s = 0,15 мм/с. Тогда порогу соответствует показание m + 2,8 s, то есть около 1,22 мм/с. Показание 1,20 мм/с даёт по формуле (3.6) z = (1,20 - 0,8) / 0,15 = 2,67 - это ниже порога, тревоги нет; показание 1,25 мм/с даёт z = 3,0 и порог превышает. Сам порог 2,8 выбран чуть ниже границы отбраковки в три стандартных отклонения: тем самым отклонение улавливается в зоне раннего предупреждения, ещё до того, как деталь будет признана браком.

Итоговое решение об аномальности собирается как логическое ИЛИ трёх независимых источников - z-правила и двух детекторов - по правилу (3.8) (листинг Г.3). Точка считается аномальной, если выполнено хотя бы одно из условий:

a = 1, если Z ≥ 2,8 или s_if(x) > t_if или O(x) > t_ecod; иначе a = 0,     (3.8)

где t_if и t_ecod - калиброванные по формуле (3.5) пороги детекторов Isolation Forest и ECOD соответственно. Главным в правиле (3.8) служит z-правило - оно одномерно, наглядно и надёжно ловит дрейф отдельного датчика, характерный для большинства сценариев [11]. ECOD и Isolation Forest его дополняют, добавляя те аномальные сочетания нескольких датчиков, которые поодиночке не видны.

Чтобы единичный шумовой выброс всё же не превращался в тревогу, поверх решающего правила работает проверка устойчивости - правило серий (листинг Г.4). Устойчивость считается отдельно по каждому каналу: для каждого датчика, вышедшего за порог, и для канала многомерных детекторов ведётся свой счётчик подряд идущих срабатываний, обновляемый по формуле (3.9):

k_c(t) = k_c(t - 1) + 1, если канал c сработал в точке t; иначе k_c(t) = 0,     (3.9)

где k_c(t) - значение счётчика канала c в момент t. Точка фиксируется как аномалия, если хотя бы по одному каналу счётчик из формулы (3.9) достигает 3. За счёт раздельного счёта шум, перепрыгивающий от такта к такту с одного датчика на другой, серию не накапливает, а устойчивый дрейф одного и того же датчика - накапливает. Три показания подряд при интервале 15 секунд соответствуют 45 секундам непрерывного превышения; стоит хотя бы одному показанию вернуться в норму, как счётчик этого канала сбрасывается в ноль и отсчёт начинается заново.

Подтверждённые аномалии записываются в таблицу результатов. Вместе с фактом срабатывания сохраняются и числа: датчик с наибольшим отклонением, величина его z-оценки и оценки обоих детекторов. Это сделано специально - метка отвечает на вопрос, аномалия или нет, а сохранённые числа показывают, насколько сильно сработало и какой именно показатель вышел за норму. Тем самым каждое срабатывание остаётся объяснимым и пригодным для разбора (НФТ5). Пример срабатывания контура детекции на введённом сценарии приведён на рисунке 3.3.
