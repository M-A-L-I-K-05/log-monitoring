# Рабочая карта литературы для ВКР

## 1. Newman S. Building Microservices : Designing Fine-Grained Systems. 2nd ed. Sebastopol : O'Reilly Media, 2021. 616 p. ISBN 978-1-492-03402-5.

Полезно: гл. «Monitoring and Observability» (логи/метрики/трейсы), гл. «Communication Styles» (синхронное HTTP-взаимодействие сервисов).

---

## 2. Richardson C. Microservices Patterns : With Examples in Java. Shelter Island : Manning Publications, 2019. 520 p. ISBN 978-1-617-29454-9.

Полезно: паттерны декомпозиции по бизнес-возможностям (database-per-service, по сервису на домен), глава об observability-паттернах (Log aggregation, Health check API).

---

## 3. Majors C., Fong-Jones L., Miranda G. Observability Engineering : Achieving Production Excellence. Sebastopol : O'Reilly Media, 2022. 318 p. ISBN 978-1-492-07644-5.

Полезно: определение observability и отличие от классического мониторинга, работа со структурированными событиями.

---

## 4. He S., Zhu J., He P., Lyu M. R. Experience Report: System Log Analysis for Anomaly Detection // 2016 IEEE 27th International Symposium on Software Reliability Engineering (ISSRE). Ottawa, 2016. P. 207-218. DOI: 10.1109/ISSRE.2016.21.

Полезно: обзор и сравнение методов детекции аномалий по логам; методика оценки (precision/recall) на размеченных данных, p. 210-215. Опора для гл. 1.3 и методики гл. 4.

---

## 5. He P., Zhu J., Zheng Z., Lyu M. R. Drain: An Online Log Parsing Approach with Fixed Depth Tree // 2017 IEEE International Conference on Web Services (ICWS). Honolulu, 2017. P. 33-40. DOI: 10.1109/ICWS.2017.13.

Полезно: обоснование, почему парсинг логов (Drain) НЕ требуется при уже структурированных JSON-логах. Опора для гл. 1.3 (отказ от Drain).

---

## 6. Liu F. T., Ting K. M., Zhou Z.-H. Isolation Forest // 2008 Eighth IEEE International Conference on Data Mining (ICDM). Pisa, 2008. P. 413-422. DOI: 10.1109/ICDM.2008.17.

Полезно: принцип изоляции аномалий, линейная сложность, описание алгоритма iTree, p. 414-416. Опора для гл. 1.3 и 3.4 (вспомогательный детектор IsolationForest).

---

## 7. Li Z., Zhao Y., Hu X., Botta N., Ionescu C., Chen G. H. ECOD: Unsupervised Outlier Detection Using Empirical Cumulative Distribution Functions // IEEE Transactions on Knowledge and Data Engineering. 2022. Vol. 35, No. 12. P. 12181-12193. DOI: 10.1109/TKDE.2022.3159580.

Полезно: непараметрический подход по эмпирической функции распределения, оценка хвостовых вероятностей, объяснимость и отсутствие тюнинга. Опора для гл. 1.3 и 3.4 (основной многомерный детектор ECOD).

---

## 8. Zhao Y., Nasrullah Z., Li Z. PyOD: A Python Toolbox for Scalable Outlier Detection // Journal of Machine Learning Research. 2019. Vol. 20, No. 96. P. 1-7.

Полезно: единый API для ECOD и IsolationForest, методы decision_function/predict, contamination. Опора для гл. 3.4 (реализация детекторов).

---

## 9. Taylor S. J., Letham B. Forecasting at Scale // The American Statistician. 2018. Vol. 72, No. 1. P. 37-45. DOI: 10.1080/00031305.2017.1380080.

Полезно: аддитивная модель тренда с интервалами неопределённости (interval_width), устойчивость к пропускам и сдвигам тренда, отключаемая сезонность. Базовая статья по Prophet, опора для гл. 1.3, 2.5, 3.5.

---

## 10. Hyndman R. J., Athanasopoulos G. Forecasting: Principles and Practice. 3rd ed. Melbourne : OTexts, 2021. URL: [https://otexts.com/fpp3/](https://otexts.com/fpp3/) (дата обращения: 01.06.2026).

Полезно: доверительные/прогнозные интервалы, ресемплинг и обработка пропусков, оценка точности прогноза. Опора для гл. 1.3 и 3.5 (согласование шкалы и горизонта прогноза).

---

## 11. Montgomery D. C. Introduction to Statistical Quality Control. 8th ed. Hoboken : John Wiley & Sons, 2020. 768 p. ISBN 978-1-119-72309-7.

Полезно: контрольные карты Шухарта, правило 3-сигма и z-оценка, run-rules (серия точек подряд) для отсечения шума. Опора для гл. 1.3 (3-сигма/z-score), гл. 3.4 (правило персистентности PERSIST_N), гл. 4.2 (валидация распределений).

---

## 12. IEC 62264-1:2013. Enterprise-control system integration. Part 1: Models and terminology. 2nd ed. Geneva : IEC, 2013.

Полезно: уровневая модель предприятия (L1-L4), функциональная иерархия (п. 5.2) и иерархия оборудования (п. 5.3), референсная привязка MES/SCADA. Опора для гл. 1.4 (промышленный контекст) и 2.1, 2.2.

---

## 13. ГОСТ Р ИСО 9001-2015. Системы менеджмента качества. Требования. Москва : Стандартинформ, 2015.

Полезно: требования к системе менеджмента качества, процессный подход; контекст для класса ПО QMS/CAQ (сервис quality). Опора для гл. 1.4 и 2.2.

---

## 14. ГОСТ Р ИСО 55000-2014. Управление активами. Общее представление, принципы и терминология. Москва : Стандартинформ, 2014.

Полезно: принципы управления активами; контекст для класса ПО CMMS/EAM (сервис maintenance). Опора для гл. 1.4.

---

## 15. ISO 14224:2016. Petroleum, petrochemical and natural gas industries. Collection and exchange of reliability and maintenance data for equipment. 3rd ed. Geneva : ISO, 2016.

Полезно: категории данных оборудование/отказы/обслуживание, «язык надёжности», структура наряда на ТО. Опора для гл. 1.4 и для модели maintenance (наряды, причины отказов).

---

## 16. OPC Unified Architecture (OPC UA) [Электронный ресурс] / OPC Foundation. URL: [https://opcfoundation.org/about/opc-technologies/opc-ua/](https://opcfoundation.org/about/opc-technologies/opc-ua/) (дата обращения: 01.06.2026).

Полезно: промышленный протокол сбора данных с оборудования (контекст класса ПО SCADA/сбор сенсорики, сервис equipment). Опора для гл. 1.4.

---

## 17. Davis J. R. (ed.) Gear Materials, Properties, and Manufacture. Materials Park : ASM International, 2005. 339 p. ISBN 978-0-871-70815-1.

Полезно: «Basic Understanding of Gears» (типы шестерён, маршрут изготовления, термообработка), p. 1-18, в т.ч. цементация/закалка p. 16-18; «Gear Failure Modes and Analysis», p. 257-291 (виды дефектов и отказов). Опора для гл. 1.2 и 2.3 (физика сценариев аномалий).

---

## 18. ISO 1328-1:2013. Cylindrical gears. ISO system of flank tolerance classification. Part 1: Definitions and allowable values of deviations relevant to flanks of gear teeth. Geneva : ISO, 2013.

Полезно: классы точности и допуски параметров (profile/lead/pitch deviation, runout). Опора для гл. 1.2 и 2.3 (спецификации измерений и пороги брака).

---

## 19. ГОСТ 1643-81. Основные нормы взаимозаменяемости. Передачи зубчатые цилиндрические. Допуски. Москва : Издательство стандартов, 1981.

---

## 20. ГОСТ Р 55090-2012. Ресурсосбережение. Наилучшие доступные технологии. Термины и определения. Москва : Стандартинформ, 2012.

---

## 21. ISO 6336-1:2019. Calculation of load capacity of spur and helical gears. Part 1: Basic principles, introduction and general influence factors. Geneva : ISO, 2019.

Полезно: режимы отказа (питтинг, излом ножки зуба, износ) и влияющие факторы. Опора для гл. 1.2 и 2.3 (обоснование критичности термообработки и сценариев деградации).

---

## 22. ГОСТ 21354-87. Передачи зубчатые цилиндрические эвольвентные внешнего зацепления. Расчёт на прочность. Москва : Издательство стандартов, 1987.

---

## 23. McKinney W. Data Structures for Statistical Computing in Python // Proceedings of the 9th Python in Science Conference (SciPy 2010). Austin, 2010. P. 56-61. DOI: 10.25080/Majora-92bf1922-00a.

Полезно: модель DataFrame, ресемплинг временных рядов, pivot. Базовая статья по pandas, опора для гл. 3.4 и 3.5 (подготовка фичей).

---

## 24. Harris C. R. [et al.]. Array Programming with NumPy // Nature. 2020. Vol. 585. P. 357-362. DOI: 10.1038/s41586-020-2649-2.

Полезно: векторные операции, на которых строятся z-оценки и масштабирование sigma. Опора для гл. 3.4, 3.5.

---

## 25. Pedregosa F. [et al.]. Scikit-learn: Machine Learning in Python // Journal of Machine Learning Research. 2011. Vol. 12. P. 2825-2830.

Полезно: базовые ML-примитивы, на которые опирается PyOD/IsolationForest. Опора для гл. 3.4.

---

## 26. FastAPI documentation [Электронный ресурс] / Ramirez S. URL: [https://fastapi.tiangolo.com/](https://fastapi.tiangolo.com/) (дата обращения: 01.06.2026).

Полезно: ASGI-эндпоинты, Pydantic-модели запросов, жизненный цикл приложения. Опора для гл. 3.1, 3.2, 3.3 (реализация микросервисов и API).

---

## 27. Docker documentation [Электронный ресурс] / Docker, Inc. URL: [https://docs.docker.com/](https://docs.docker.com/) (дата обращения: 01.06.2026).

---

## 28. Grafana Loki documentation [Электронный ресурс] / Grafana Labs. URL: [https://grafana.com/docs/loki/latest/](https://grafana.com/docs/loki/latest/) (дата обращения: 01.06.2026).

Полезно: модель меток, LogQL, query_range, лимиты запроса, связка Promtail → Loki → Grafana. Опора для гл. 1.4, 2.4, 3.5, 3.7.

---

## 29. PostgreSQL documentation [Электронный ресурс] / PostgreSQL Global Development Group. URL: [https://www.postgresql.org/docs/](https://www.postgresql.org/docs/) (дата обращения: 01.06.2026).

Полезно: схема таблиц, индексы, UPSERT (ON CONFLICT), оконные операции. Опора для гл. 2.6 и 3.6.
